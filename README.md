# Для чего этот проект

Этот проект создан для облегчения отслеживания задач.

# Что он делает

Позволяет отслеживать задачи и повторять их согласно заданному интервалу.

# Список выполненных заданий со звёздочкой

Задания повышенной трудности не выполнялись.

# Инструкция по запуску (macOS)
1. Скачать зависимости. Для этого в родительской директории в консоли вводим `go mod tidy`.

2. Для запуска приложения в родительской директории в консоли вводим `go run main.go`.

После этого проект запустится на порту `7540`.

Для использования приложения, в браузере переходим по ссылке `http://localhost:7540/`.

# Запуск тестов

Настройки тестов в файле `settings.go` остаются дефолтными без изменений.

Для запуска тестов, в родительской директории в консоли вводим `go test ./tests`.

# Файлы

В директории `tests` находятся тесты для проверки API, которое должно быть реализовано в веб-сервере.

Директория `web` содержит файлы фронтенда.

В файле `utils` пакета `api` находятся функции отправки ошибки и JSON объекта на клиент.
